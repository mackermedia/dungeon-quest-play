# Dungeon Quest

A Zelda-style dungeon game. Phaser 3, one `index.html`, no build step.

Run it:

```
python3 -m http.server 8000
# open http://localhost:8000
```

Controls: arrows or WASD to move, Space to swing the sword.

Art: [Kenney](https://kenney.nl) packs, CC0. See `assets/kenney/LICENSE-kenney.txt`.
